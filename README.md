# Annales D1

Annales interactives façon UNESS : une question à la fois, navigateur de questions, correction détaillée, score, chrono.

Deux modes : **Entraînement** (correction après chaque validation) et **Examen** (chrono, on valide et on passe à la suite, correction seulement à la fin).

- **En ligne** : https://lzy270.github.io/annales-d1/
- **Hors ligne** : télécharge `Annales_D1_hors_ligne.html` et ouvre-le dans ton navigateur (un seul fichier, images incluses).

Chapitres : UE2 génétique, UE8 neuro (anatomie, physiologie, sémiologie, histo-embryo, pharmaco).
